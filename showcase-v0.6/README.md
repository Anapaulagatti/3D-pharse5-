# Playful Hangeul Town v0.6 — prototype B + T1

Đây là bản dựng thử để duyệt, chưa thay website v0.5.

1. Giải nén toàn bộ ZIP vào một thư mục.
2. Windows: chạy START_WINDOWS.cmd (cần Python3). macOS/Linux: mở Terminal trong thư mục rồi chạy `python3 start.py`.
3. Trình duyệt sẽ mở bản 3D thật. Giữ cửa sổ terminal mở; Ctrl+C để dừng. Không cần Node, Blender, Internet hay API key.

Bấm **Bắt đầu khám phá**, chạm sân rồi dùng WASD/phím mũi tên; Shift chạy, Space nhảy, E mở cửa khi ở gần. Điện thoại có phím cảm ứng. Chạm Nari/đèn; Gặp Nari để xem gần. Góc nhìn & tùy chỉnh chứa chất lượng, camera, animation, biểu cảm và giảm chuyển động. Mặc định tôn trọng OS reduced-motion.

Nếu chỉ thấy mã HTML trong trình xem file ChatGPT/GitHub, hãy tải ZIP xuống và dùng HTTP launcher trên. Trình xem source không chạy WebGL. WebGL không khả dụng sẽ dùng ảnh render v0.6 thật.

Một nhân vật + một nhà/quảng trường, không multiplayer, backend, NPC hay district mới. 20clips xuất; bộ hành động prototype đã được kiểm tra riêng trong quality reports. Dance/eye-tracking/full-town không được tuyên bố hoàn thành. FPS thiết bị thật chưa đo. Phiên bản này chờ người dùng xem và chưa được phê duyệt xuất bản công khai.
