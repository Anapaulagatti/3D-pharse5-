# KOREAN ARENA — CHARACTER STYLE OVERRIDE
## Chibi Pixel Avatar Rebuild Only

The environment direction is becoming acceptable, but the PLAYER CHARACTER is still not approved.

Current problem:
- The world/buildings/trees are more visually appealing now,
- but the character still feels flat, weak, NPC-like, and not “chibi pixel avatar” enough.
- The player looks too much like a simple front-facing tiny sprite.
- It does not yet feel like a collectible, customizable social-game avatar.

We are NOT doing a full environment reset right now.

## TASK
Keep the current environment direction as the temporary world foundation.

Focus ONLY on rebuilding the player/avatar visual language into a true **chibi pixel avatar** style.

---

## 1. TARGET CHARACTER STYLE

Create a new ORIGINAL Korean Arena player character style with these properties:

- cute **chibi pixel** proportions,
- larger head-to-body ratio,
- strong silhouette,
- clearly readable hairstyle,
- clearly readable face,
- expressive eyes,
- cleaner outfit separation,
- visible hands/arms/legs,
- readable accessory hooks,
- attractive enough for cosmetics/outfit progression,
- suitable for a social multiplayer learning game.

The avatar must feel like a real **player character**, not a background NPC.

It should feel closer to a polished social RPG avatar:
- cute,
- readable,
- stylish,
- collectible,
- easy to recognize in a crowd.

Do NOT copy sprites from any existing game.

---

## 2. SPECIFIC VISUAL REQUIREMENTS

### Body proportions
Use a more chibi structure:
- larger head,
- slightly shorter torso,
- more readable limbs,
- larger face area,
- clearer stance.

### Face
The face must be more expressive:
- eyes easy to read at gameplay scale,
- small but readable mouth,
- optional blush / cheek highlight if suitable,
- clear emotional changes.

### Hair
Hair must have a stronger shape:
- not a flat dark blob,
- readable outline,
- front/back shape,
- enough identity to distinguish one avatar from another.

### Outfit
Outfit must show clear layers:
- top,
- bottom,
- shoes,
- optional bag/scarf/badge/book/satchel.

Avoid muddy colors.

### Limbs
Arms and legs must read clearly.
Avoid a silhouette where the body looks like one compact block.

---

## 3. DIRECTIONAL SPRITES

Create proper 4-direction character sprites:
- front
- back
- left
- right

Do NOT fake all directions by minimal edits.
Each direction must feel genuinely authored.

The player must no longer look like “just one face pasted in different movement states.”

Back view must have:
- readable back hair shape,
- back outfit detail,
- correct shoulder/arm placement.

Side views must have:
- visible profile,
- readable nose/face direction if appropriate,
- correct arm swing,
- clearer depth.

---

## 4. REQUIRED ANIMATIONS

Create and test real animation frames for:

- idle down / up / left / right
- walk down / up / left / right
- run down / up / left / right
- blink
- wave
- happy/celebrate emote
- one social idle pose

Animation must remain cute and readable.

Run cycle must feel different from walk cycle.

Idle must feel alive:
- tiny bounce,
- blink,
- subtle breathing,
- micro hand or accessory motion if suitable.

---

## 5. EXPRESSION STATES

Character mood must visibly change.

At minimum, create expression variants for:
- neutral
- happy
- focused
- surprised

If the avatar is used later in learning content, these expressions will support dialogue and quest scenes.
