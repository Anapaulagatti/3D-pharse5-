# Phase 1B controlled character production

The Phase 1 engine, UI, preferences, world and original Juni remain accepted and frozen. This work replaces neither the world nor the player controller.

## Why the prior pilot failed

The earlier model-generated strips used eight nominal cells but did not author opposite-leg contact phases. Their source scale also disagreed with the registration guide. Naming eight frames is insufficient. The old rejected sources and reports remain immutable.

## New authoring route

1. Use the built-in image tool for original, separated-limb directional artwork, keeping each character's identity reference and Juni as the scale/style peer.
2. Prepare a controlled native sprite finish with one fixed body scale and foot anchor, binary alpha, shared palette, and explicit native review. No independent frame bounding-box fitting.
3. Cut authored pixels into named head/body, upper/lower limb and shoe layers. Bake joint-based pose keys and inbetweens offline with integer placement/nearest sampling. This is layered animation of authored artwork, not a replacement gameplay rig or a translated static portrait.
4. Validate Haneul's front walk first: eight distinct images, opposite contact phases, arm counter-swing, weight transfer, foot placement, silhouette and loop inspection at 1:1 and actual speed. Reject and correct the pilot before multiplying it.
5. Only complete, inspected packs may become playable in the existing registry. Preserve failed candidates separately.

Native contract: 96×112, anchor (48,100), Juni-compatible visible height and ground envelope; no changes to world collision, camera, movement speeds or original Juni files. A joint transform must not alter asymmetric identity/accessory ownership. Directions with asymmetry use independent authored views.

Art-source disclosure: host-image artwork plus offline, explicitly authored layer animation/registration. Generated concept masters alone do not qualify as native animation. Numerical checks do not grant human artistic approval.
