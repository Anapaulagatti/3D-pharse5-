# Character art provenance

Three new built-in `image_gen.imagegen` calls produced the independent Haneul, Bomi and Minjun four-view sources. No paid external image/video API was invoked and no provider key was used. Existing Phase1 identity masters and the immutable native Juni reference were supplied as identity/style references. Originals, prompts and SHA256 records are retained under `assets-src/characters/phase1b/<id>/`.

The high-resolution source is explicitly **not** represented as a native logical grid. `native-finish.json` records one fixed source-to-native scale per character, premultiplied area finish, binary alpha and96-color directional palette. Native faces, clothing silhouettes and proportions were reviewed against Juni. There is no per-frame bounding-box fitting, global sharpening or runtime sprite scaling.

`rig.json` records manually authored masks, joints, shared native ground axis, calibrated soles, limb pose amplitudes and the small source-cloth clone rectangles needed behind displaced arms/accessories. The base images are segmented into actual upper/lower limbs and shoes. Offline bone projection, arm counter-swing, alternate phase offsets, controlled weight transfer and run flight produce the frames, with nearest sampling onto the native grid. The fixed0.68 FAR-leg lighting shade makes profile depth readable; the final shared palette includes these fixed shadow colors. This is **host-image artwork animated through explicitly authored offline layers**, not code-drawn replacement people or a new runtime character engine.

Four independent view images preserve asymmetric hair, ribbon, watch and bag ownership. Rig names L/R are screen-layer labels, not an assertion of anatomical left/right in every view. No completed directional image is mirrored. Minjun's bag/strap and Bomi's belt ornament remain torso-owned. Character frames do not include environmental ground/shadow patches or any world artwork.

Each pack contains112 frame slots:64 distinct walk/run pixel images,8 idle frames,24 start/stop frames and16 emote frames. Transition clips may legitimately reuse directional poses; no reused transition pose is counted as a new locomotion frame. Twelve ordered view-to-view turn clips use those independently authored views. The final atlas is1152×1120 with untrimmed96×112 cells and native anchor(48,100). Sources and clips are included alongside the playable package.

Haneul's front walk was inspected before multiplying the production method. Later registration QA corrected source-pose staggering in profile views, sole alignment and FAR-leg depth. Rejected/intermediate validator results are retained as historical iterations. `forge-qa-release/` is the final unmodified-threshold run; `forge-warnings.json` reproduces every remaining WARN with its exact values, thresholds and affected frames. A warning about auto-luminance near/far identification at crossing poses is not relabelled PASS. Numerical checks do not approve artistic anatomy or perceived foot sliding; actual-speed Phaser recordings are the review evidence.

Tooling: pinned Sprite Forge `5324342fdfab72430f4e9604f3fe427009f8596d` (generate2dsprite and pixel QA); pinned Character Animation Creator `9ce98dffb98c84488fe7b99b62c49fabee20abd6` retained from Phase1. Existing failed eight-pose strips remain untouched under the prior Phase1 namespace and are not runtime assets.

Reproduce the native pack from retained source: `python tools/phase1b/prepare.py haneul`, then `python tools/phase1b/animate.py haneul` (likewise Bomi/Minjun). `--pilot` emits the front-walk pilot only. Pillow/numpy are authoring dependencies, not game runtime dependencies. Run `python tools/phase1b/art_audit.py` and the pinned Forge QA, then the standard unit/build/E2E checks before reactivating any altered pack. Preserve historical sources/checkpoints.
