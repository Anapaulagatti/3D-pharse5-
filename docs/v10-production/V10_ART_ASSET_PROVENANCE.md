`art-provenance.json` traces every measured source crop and every final native image to its new original; source boxes, binary-alpha threshold, uniform scale, frame size, alignment and hashes are recorded.44 native sprites include23 original major property images and21 furnishings/landmarks;16 original64px material images complete the60-image kit. The shared192-color palette applies only to new southern images. `pixel-finish.json` verifies each final hash, palette limit and binary alpha. The protected north is outside this processing.

Actual Forge extraction uses measured empty-alpha gutters, transparent padding and strict edge/clipping checks, all components retained. Source clipping was rejected, never excused by relaxed QC. Nonuniform source sheets required measured cell boundaries; the first strict attempts failed and were corrected. Forge terrain extraction verifies16 isolated cells; this is **not** a claim of Wang/autotile coverage or mathematically seamless textures. Material repetition and native palette finishing are visible in the engine captures.

`art-processing-log.json` retains exact tool commands, outputs and failures; persisted extraction/palette/material receipts are in `qa/production/`. Original command paths refer to the authoring cache and are historical receipts, not setup dependencies. Native assets and runtime hashes are independently verified by offline setup. Raw illustrations were uniformly reduced and palette-finished, never replaced by procedural building boxes.
