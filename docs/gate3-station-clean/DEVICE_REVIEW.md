# Actual-device handoff — NOT TESTED

Physical Android Chrome/iPhone Safari and hardware WebGL performance remain NOT TESTED. Chromium emulation is only a regression check.

1. Extract the full ZIP, run `python3 start_review.py`. For trusted private Wi-Fi review only, `--lan` enables access through the machine's private LAN address; this is not public deployment.
2. Record device/model, OS, browser version, landscape size/DPR, checkpoint, battery/power settings and actual screen video.
3. Open the active fresh station. Check full roof/clock/sign, facade/door/Juni scale, new paving, old-art absence, foreground depth and crisp native pixels. The empty-site link is purge evidence; archived BEFORE images are not a playable old station.
4. Walk to the entrance, across the forecourt/road and to the eastern platform and back. Test the now-open former8px ownership strip and the narrow side passage. Record all visual/collision failures.
5. Test joystick gesture isolation, Scenic drag/pinch, Tour Pause/Skip/collapse/Return, original Juni-position preservation and reduced motion.
6. Visit the unchanged other regions and walk at least10 minutes. Record stalls, missing chunks, reloads/heat/termination; a64MiB cache setting is not measured total device memory or60fps proof.
7. Open `···` → Export test report. Keep downloaded JSON, device details, UTC time, screen video and PASS/FAIL/NOT TESTED notes together.

Review checkpoint `checkpoint/g3d-station-clean-review-20261025`. Use [report template](DEVICE_REPORT_TEMPLATE.json). [Extracted-package emulation](package-smoke.json) and [exported emulated session](package-emulated-session.json) cannot certify actual phones.
