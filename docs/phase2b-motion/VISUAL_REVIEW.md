Capture note: one initial Yuna recording failed an overly tight4px index0-distance check. Because index0 occupies1/8stride, two samples of that phase can differ within that interval; the corrected capture bound is stride/8, documented in the recorder. This changes no Forge threshold. The incomplete attempt is excluded; the delivered Yuna/Hyunwoo captures were recorded afresh and all final126 loops pass the stated bound.
