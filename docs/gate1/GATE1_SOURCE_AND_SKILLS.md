## Failures retained, not relabelled

- Raw low-alpha source halo tripped strict cell-edge checks. Standard binary128 alpha normalization removed the faint background; the same strict edge/component/drop checks stayed in force. The first regular-grid extraction warned `tall or wide props in a square grid (aspect > 1.6)` for bench-front409×201, bench-back409×182, light151×428, flowerbox433×216. Measured custom cells resolved the warning; final extracted pixels were verified identical before reuse of the finishing results.
- A256-entry palette lacked a transparency slot; apply correctly refused it. A fresh255-color palette leaves index255 for transparency, and final apply passed. Failed receipts remain in the processing log.
- Initial bundle anchors used the wrong schema; corrected to point/approach data before hashing. Initial nav reported one1824-cell pocket behind the closed off-slice heritage boundary. That visible closed forecourt is now explicitly outside the sample's playable extent; no public route/entrance was blocked to hide a failure.
- The first2× checker compared RGB bytes with RGBA bytes, and the first portable verifier read the old generic `dist` path. Canonical RGBA comparison and the actual `dist-gate1` path fixed the verification code, without changing art or relaxing thresholds.
- The first npm install could not write the global npm cache and retried tarballs. An existing working dependency tree was copied after exact lockfile equality and verified by `npm ls`; no version/lock change, integrity flag bypass or working-tool reinstall. Type/lint/unit/build/runtime checks then passed. This is reuse, not a claim of a fresh successful dependency download.

## Reproduce stored outputs without generation

Node24+, Python3.12/Pillow12.3 and Chromium are used. Run `npm ci --ignore-scripts --cache .cache/npm` in a fresh writable checkout, or reuse the verified exact-lock dependency tree. `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test`, `npm run assets:check`, `python3 tools/gate1_validate.py`, then `npx vite build --config gate1.vite.config.ts` and `python3 tools/gate1_package.py`. Ordinary setup/build never generates imagery or calls providers. `npm run dev -- --port 4230` serves the internal sample at `/3D-pharse5-/gate1-street.html`; loopback is not a public preview.

Authoring uses retained originals, native assets, plan and measured custom boxes; optional Forge cache is not shipped into production. New output destinations are required by Forge. Refresh hashes/nav proofs after authorized geometry changes. The full graybox planner/compiler is not run for Gate1. `review-state.json` and AGENTS.md keep Gate2 locked and limit feedback correction to one pass.
