# Palace cleanup — physical device handoff / NOT TESTED

Physical Android Chrome/iPhone Safari and hardware WebGL performance are NOT TESTED. Chromium emulation is a regression check only.

1. Extract ZIP and run `python3 start_review.py`; use `--lan` only for trusted private Wi-Fi review, never public deployment.
2. Record device/model, OS/browser version, landscape dimensions/DPR, power settings, checkpoint and actual screen video.
3. Open `palace-combined-local`, `palace-axis-local`, `palace-access-local`, `palace-front-local`. Compare native before/after images. Walk the axis from lower path to main entrance and back; follow the short right branch to the existing exterior steps and return. Check idle/stop/turn contact and Juni visibility beneath the right gate lantern.
4. Check unchanged western hanok, Hanbit and both bridges using preservation links. Do not infer new artistic acceptance from these checks.
5. Test original joystick isolation, WASD where available, Scenic drag/pinch, Tour Pause/Skip/collapse/Return and reduced motion.
6. Record real stalls, missing chunks, reloads, heat and termination. A64MiB cache budget is not measured total phone memory or60fps evidence.
7. Open `···` → Export test report. Save JSON together with device details, UTC time, screen video and PASS/FAIL/NOT TESTED notes.

Checkpoint `checkpoint/g3d-palace-cleanup-review-20261025`. [Report template](DEVICE_REPORT_TEMPLATE.json). No unsupported physical-device PASS.
