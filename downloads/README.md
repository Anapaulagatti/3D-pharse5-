# Gói xem showcase v0.2

- **showcase-v0.2-http.zip**: giải nén, Windows mở `START_WINDOWS.cmd`; macOS/Linux chạy `python3 start.py`. Launcher phục vụ HTML qua HTTP và tự mở trình duyệt trên máy bạn. Cần Python 3; không cần Node/Blender/npm.
- **showcase-v0.2-static.zip**: `index.html` ở gốc, dùng upload lên static hosting. Chưa công khai; xem `showcase/DEPLOYMENT.md` và xin chấp thuận trước Publish/Deploy.
- **package-manifest.json**: checksum/size của ZIP và HTML gốc.

Mở ZIP/HTML trong trình xem file của ChatGPT/Codex chỉ xem source. Tải về máy, giải nén và chạy launcher để xem bản tương tác. Các gói chỉ đóng gói HTML đã có, không tái tạo art/model.
