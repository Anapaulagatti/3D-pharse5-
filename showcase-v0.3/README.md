# Korean Arena 3D Studio v0.3 — Living Hanok Showcase

Bản v0.3 đã xuất bản tại [https://anapaulagatti.github.io/3D-pharse5-/](https://anapaulagatti.github.io/3D-pharse5-/), sau khi bạn cho phép. Gói ZIP review trước đây vẫn được giữ để xem cục bộ.

## Xem tương tác trên máy cá nhân

1. Giải nén toàn bộ ZIP vào một thư mục.
2. Windows: mở START_WINDOWS.cmd. macOS/Linux: mở Terminal trong thư mục vừa giải nén và chạy `python3 start.py`. Cần Python 3.
3. Trình duyệt tự mở ứng dụng thật. Giữ cửa sổ server mở trong khi xem; Ctrl+C để dừng. Không cần Node, Blender hoặc mạng.

Mở index.html trong ChatGPT/Codex/GitHub có thể chỉ hiện mã nguồn; dùng launcher HTTP ở trên. Launcher chỉ phục vụ thư mục ZIP trên chính máy bạn.

## Điểm cần xem

- Đèn lồng, lá mận, giấy hanji và chuyển động linh vật; sáu trạng thái rõ ràng.
- Chạm linh vật để chào/ăn mừng rồi trở về Idle; chạm đèn/cây hoặc dùng các nút tương tác.
- Nắng dịu / Chiều ấm / Đêm đèn. Góc nhìn Mái hanok / Vườn mận / Đài gốm.
- Kéo xoay và cuộn/pinch zoom. Góc nhìn điện ảnh là tùy chọn, dừng khi bạn kéo xoay.
- Giảm chuyển động tuân theo hệ điều hành; bạn có thể chủ động đổi checkbox. Tạm dừng giữ yên các chuyển động.
- Chất lượng Thấp / Vừa / Cao; điện thoại mặc định Thấp. Fallback dùng ảnh 3D gốc khi WebGL không khả dụng.

V0.2 .blend/GLB/texture/animation và checkpoint được giữ nguyên; v0.3 thêm layer chi tiết riêng và xử lý biểu cảm ở runtime. Không có district mới, tài khoản, backend, âm thanh hoặc dịch vụ trả phí.

Thành tích FPS phần cứng/điện thoại thật chưa được đo; kiểm tra cloud dùng SwiftShader. Không có cam kết 60 FPS.
